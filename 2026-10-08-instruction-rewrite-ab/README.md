# 지시문을 "규칙 덧붙이기" 대신 "목적과 이유"로 다시 쓰면 성능이 유지되나 (2026-10-08 ~ 10-09)

## 결론

- **역할 지침 개편은 버렸다.** 59장면 × 4모델을 한 번씩 돌린 비교에서 지금판 159 대 개편판 160(236칸 중 통과)으로 동점이었고, 갈린 칸을 3번씩 다시 돌린 것까지 합치면 238 대 229(369실행)로 개편판이 밀렸다. Opus가 잘하던 두 장면에서 개편판이 3번 모두 졌다.
- **스킬 재작성은 올렸다.** 스킬 6개를 다시 쓴 판이 공식판보다 내용 통과 13/24 → 17/24였고 진 곳이 없었다. 공개 PR로 냈다: [keepitmello/Rubato#26](https://github.com/keepitmello/Rubato/pull/26) (스킬 6개, +195/−518줄, 코드 변경 없음, 2026-10-09 병합).

## 물은 것

Rubato(형이 만든 AI 에이전트 하네스)의 지시문과 스킬(필요할 때 모델이 열어 읽는 작업 안내 문서)은 실패가 생길 때마다 규칙을 한 줄씩 덧붙이며 커졌다. 정해진 순서·관문 대신 "무엇을 구별해야 하는지와 그 이유"를 기존 문단에 담는 방식으로 다시 쓰면, 글은 짧아지는데(바뀐 본문 20개 기준 −26%) 리드의 판단은 유지될까. 큰 효과보다 "방식을 바꿔도 손해가 없나"가 질문이었다.

## 바꾼 것

| 판 | 내용 |
|---|---|
| A | 그때 설치본 그대로 |
| B | 개편 제안 묶음(절차를 판단 조건·이유로 바꾼 재작성본)에, 꼭 살릴 문장 목록을 내가 승인해 합친 판. 역할 지침(공통·리드·말투), 전역 지침, 스킬 21개 파일 |

나중 스킬 시험에서는 아래 판을 더 만들었다.

| 판 | 내용 |
|---|---|
| A2 / E / F | 개인 설정판 스킬 / 한국어로 개편한 스킬 / 같은 개편을 영어로 옮긴 스킬 |
| O / P | PR 대상 스킬 파일만 공식판 / PR #26판으로 바꾼 것 (나머지 동일) |

## 어떻게 쟀나

- 장면: Rubato 저장소에 있던 회귀 시험 장면 51개 + 이번 변경에 맞춰 새로 쓴 8개 = 59개. 뒤에 1개 추가. 필요한 장면은 작업 폴더·앞 대화를 고정 자료로 만들었다.
- 모델 4개: Claude Opus 5.5(생각 high), GPT-6.1 Sol(high), GPT-6 Astra(xhigh), DeepSeek v4.1 flash(high). 뒤에 GPT-6 Astra medium을 일부 장면에 추가.
- 실행: 판마다 깨끗한 임시 HOME을 만들고 Rubato CLI로 한 턴(일부 2~3턴)씩. 하위 세션을 띄우는 호출은 첫 호출에서 멈추고 그 호출 자체를 채점. 외부 조사 도구는 가짜로 바꿔 실제 호출이 없게 했다.
- 사전 확인: 모델로 가는 실제 요청 본문을 로컬에서 잡아 두 판을 비교했다. 차이가 바꾼 지시문 줄에만 있고 설명 안 되는 차이는 0줄임을 확인했다. 이 과정에서 기존 스킬 하나가 설명 줄의 YAML 문법 오류로 모델에게 아예 안 보이고 있던 결함을 찾았다.
- 횟수: 처음엔 칸(장면 × 모델 × 판)마다 1번. 그 뒤 A·B가 갈린 칸과 새로 쓴 장면을 중심으로 3번까지 다시 돌렸다.
- 채점: AI 채점자 한 명(Claude Opus 5.5, high)이 판·모델을 모른 채 기준마다 통과/실패를 매기고 근거 문장을 인용했다. 채점 순서는 섞었다. 채점 판정 985건.

- 모델별 1번씩 비교: Opus 42 대 43, Sol 39 대 42, Astra 44 대 42, DeepSeek 34 대 33 (각 59칸).

- 두 판 다 못하는 장면도 드러났다(이번 변경과 무관한 지금 설정의 약점): 규칙을 한 곳에만 두기 0/4, 그림을 열어 확인한 뒤 링크하기 0/4 등.

## 시험 도구에서 잡은 결함

후속 턴을 이어 보내는 실행 인자 순서가 틀려, 앞 대화가 필요한 103칸(스킬 시험 2칸 포함)이 사실상 새 대화로 시작돼 있었다. 답이 그럴듯해서 채점까지 갔다가 뒤늦게 찾았다. 103칸을 다시 돌리고 다시 채점했고, 위 숫자는 다시 돌린 결과다. 같은 실수를 막으려고 실행 전 인자 검사와 실행 뒤 세션 내용 검사를 넣고, 그 결함 기록으로 테스트를 만들었다.
