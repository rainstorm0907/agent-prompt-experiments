# AI 에이전트 지시문 실험 기록

AI 에이전트에게 일을 맡기다 실패한 순간을 골라, 지시문(시스템 프롬프트) 한 문단이나 스킬 문서를 고친 판과 고치기 전 판을 같은 자료로 다시 돌려 비교한 기록이다. 직접 쓰는 에이전트 앱 Rubato 위에서 했고, 결과에 따라 채택하거나 버렸다.

## 읽는 법

**숫자.** "3/3"은 3번 돌려 3번 통과라는 뜻이다. 조건마다 1~3번이라 통계적 증명이 아니라, 고칠 후보를 걸러낸 수준이다. 각 보고서에 한계를 따로 적었다.

**채점.** 점수는 모두 AI 모델이 매겼다. 채점자는 어느 판의 답인지 모르게 이름을 가렸다. 채점자 구성은 실험마다 다르다: DeepSeek·GPT-6 Astra 두 명(10-10, 10-11), Claude Opus 한 명(10-08, 10-14 1바퀴), Opus·GPT-6.1 Sol 두 명(10-14 2·3바퀴). 두 명이면 서로 모르게 따로 채점했다. 이름을 가리지 않고 시험을 돌린 AI 세션이 직접 읽어 판정한 부분은 보고서에 표시했다. 내가 직접 고른 판정은 점수와 따로 적었다.

**자주 쓴 시험 방식.** 실제로 실패한 대화 앞부분을 세션 파일로 고정한다 → 다음 사용자 말만 넣고 명령줄로 한 턴을 돌린다 → 지시문만 다른 두 판을 비교한다. 고친 쪽이 다른 데서 나빠지지 않았는지 반대 방향 장면(뻔한 요청엔 질문 없이 바로 하나, 짧은 승인엔 바로 하나)도 늘 같이 돌렸다.

**용어.**

- Rubato: 내가 쓰는 오픈소스 AI 에이전트 앱이자 하네스([keepitmello/Rubato](https://github.com/keepitmello/Rubato))(모델을 감싸 지시문·도구·기억을 붙여 실행하는 틀). Claude, GPT, DeepSeek을 같은 지시문 체계로 돌린다.
- 리드: 사용자와 직접 대화하는 주 AI 세션. 필요하면 하위 세션에 일을 나눠 맡긴다.
- 지시문, 역할 지침: 리드에게 매 대화 실리는 시스템 프롬프트 파일(`base.pi.md` 공통, `core-lead.pi.md` 리드용).
- 스킬: 필요할 때 모델이 열어 읽는 작업 안내 문서.
- Outpost: 실험 설계와 결과 해석을 ChatGPT Pro에 자문받는 도구.
- 모델: Opus = Claude Opus 5.5, Astra = GPT-6 Astra, Sol = GPT-6.1 Sol, DeepSeek = DeepSeek v4.1 flash(피험 모델 기준. 채점에 쓴 DeepSeek 버전은 원래 기록에 없다).

## 누가 무엇을 했나

- **질문 고르기, 실험 지시, 결과 읽기, 채택 결정은 내가 했다.** 시험 스크립트 작성·실행·채점 요청·원래 보고서 작성은 내가 맡긴 AI 세션(주로 Rubato 리드, Claude Opus 5.5)이 했다. 보고서의 "직접 읽음"은 그 AI 세션의 판정이다.
- **Rubato에 반영한 커밋과 PR은 내 계정([rainstorm0907](https://github.com/rainstorm0907))으로 올렸다.**

## 넣지 않은 것

- 결론이 없는 기록 3개: 맨 Claude Code 대 Rubato 비교(설계만 하고 실행 안 함), 대화 압축 요약 언어 시험(결론 문서 없음), Opus용 작업방식 프롬프트(아직 시험 안 함).
- 개인 설정 저장소를 대상으로 한 시험과 검토(압축 뒤 연속성, 설정 후보 비교, 스킬 묶음 설치 전 확인 등).
- 시험이 아닌 기록(세션 시작 안내서, 디자인 회고, 기록 파일 대응표).
- 원본 실행 기록 약 415MB.
